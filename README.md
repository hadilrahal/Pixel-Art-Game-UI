# Pixel Art Game UI – Piskel

## Overview

A dark fantasy-inspired pixel art game menu designed using Piskel.

This project focuses on creating custom user interface assets for video games, including menu buttons, decorative frames, and pixel art elements.

## Features

- Custom pixel art menu design
- New Game, Play, and Quit buttons
- Dark fantasy-inspired visual style
- Decorative borders and red gemstone elements
- Consistent color palette and pixel-level detailing

## Tools

- Piskel
- Pixel Art
- Game UI Design
